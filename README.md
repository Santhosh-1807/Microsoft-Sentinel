# Microsoft Sentinel — Introduction & Architecture

## Objective

To understand the fundamentals, capabilities, and architecture
of Microsoft Sentinel and how it supports Security Operations
Center (SOC) activities.

## What is Microsoft Sentinel?

Microsoft Sentinel is a cloud-native security platform used for
security monitoring, threat detection, investigation, and response.

## Key Capabilities

The major capabilities introduced in this video include:

- Security monitoring
- Threat detection
- Threat investigation
- Threat hunting
- Security analytics
- Security automation
- Incident response

## Microsoft Sentinel Architecture

The basic Sentinel workflow can be represented as:

Data Sources
     ↓
Data Collection
     ↓
Microsoft Sentinel
     ↓
Log Analytics Workspace
     ↓
Security Analytics
     ↓
Detection
     ↓
Alerts / Incidents
     ↓
Investigation
     ↓
Response

## SOC Use Case

A SOC analyst can use Microsoft Sentinel to collect security
telemetry, identify suspicious activity, investigate incidents,
and respond to security threats.
