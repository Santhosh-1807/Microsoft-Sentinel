# Microsoft Sentinel Notebooks

## Overview

This project explores Microsoft Sentinel Notebooks and their use in security investigations and threat hunting with Jupyter Notebooks, Python, and MSTICPy.

## Objectives

- Understand Microsoft Sentinel Notebooks.
- Learn how Jupyter Notebooks support security investigations.
- Understand the role of Python in cybersecurity.
- Explore MSTICPy for threat hunting and data analysis.
- Understand how notebooks help analyze security events.

## Technologies Used

- Microsoft Sentinel
- Microsoft Azure
- Jupyter Notebook
- Python
- MSTICPy
- Kusto Query Language (KQL)

## What Are Microsoft Sentinel Notebooks?

Microsoft Sentinel Notebooks provide an interactive environment for analyzing security data.

Security analysts can use notebooks to run code, investigate suspicious activities, query data, and visualize investigation results.

## What Is Jupyter Notebook?

Jupyter Notebook is an interactive environment that allows users to execute code in individual cells and view the results.

In cybersecurity, it can be used for:
- Security data analysis
- Threat hunting
- Investigation automation
- Data visualization
- Investigation documentation

## What Is MSTICPy?

MSTICPy is an open-source Python library designed to support cybersecurity investigations and threat hunting.

It provides tools for querying security data, enriching entities, analyzing suspicious activity, and visualizing investigation results.

## Investigation Workflow

1. Identify a suspicious alert or security event.
2. Collect relevant security data.
3. Query available data sources.
4. Analyze events using Python and investigation tools.
5. Enrich relevant entities when appropriate.
6. Visualize the findings.
7. Document the investigation results.
8. Recommend appropriate response actions.

## SOC Analyst Use Cases

- Visualizing event timelines.

- Automating repetitive investigation tasks.
